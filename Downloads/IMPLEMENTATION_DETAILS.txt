================================================================================
API ENDPOINTS INTEGRATED
================================================================================

channels.js:
  GET /api/channels - Load marketplace configurations
  GET /api/channels/[marketplace]/status - Check per-user connection
  POST /api/channels/test - Test connection with stored credentials
  POST /api/channels/manual-package - Generate listing packages
  OAuth: eBay auth.ebay.com, Etsy www.etsy.com/oauth/connect

social.js:
  GET /api/social/status - Load social platform status for user
  POST /api/oauth/authorize - Start OAuth flow for any platform
  Platform callbacks: /api/oauth/[platform]/callback

================================================================================
AUTHENTICATION & SECURITY
================================================================================

- Session-based authentication (requireSession utility)
- Bearer token in Authorization header (authedFetch)
- CSRF state tokens for OAuth (eBay)
- PKCE code challenge for public clients (Etsy)
- Encrypted credential storage (Supabase)
- No credentials exposed client-side
- Session validation on all API calls
