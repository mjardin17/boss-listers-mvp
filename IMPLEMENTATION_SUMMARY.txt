API INTEGRATION
================================================================================

ENDPOINT 1: GET /api/products/[sku]
  Purpose: Lookup inventory by SKU
  Request:  GET /api/products/SKU-123-456
  Response: { ok: true, product: {...} }
  Error:    { ok: false, error: "Unknown SKU: SKU-123-456" }
  Time:     300-500ms (Supabase REST)
  Usage:    Auto-fill form on successful lookup

ENDPOINT 2: GET /api/channels/ebay/category-suggest?q=<title>
  Purpose: Get eBay category suggestions for a title
  Request:  GET /api/channels/ebay/category-suggest?q=Vintage+leather+wallet
  Response: { ok: true, best: {...}, suggestions: [...] }
  Time:     1-2s (eBay Taxonomy API)
  Usage:    Populate category dropdown in form

ENDPOINT 3: POST /api/channels/ebay/create-listing
  Purpose: Create (and publish) an eBay listing
  Request:  POST /api/channels/ebay/create-listing
            Headers: Authorization: Bearer <token>
            Body:    { product: {...}, policies: {...}, dryRun: false, confirm: "PUBLISH_LIVE" }
  Response: { ok: true, sku, offer_id, listing_id, steps, payloads }
  Error:    { ok: false, error, code, step?, offerId? }
  Time:     5-15s (Bridge → eBay API)
  Usage:    Submit form to create real eBay listing
